# STORY WRITER — how to invent the topic, write the script and list the SFX (do this BEFORE any code)

The user may say only "nayi video banao" / give only a topic / give a full script. Do the missing parts yourself, in this order:

## A. Pick a topic (or take the user's)
1. Read `casting_log.json` and `TOPIC_BANK.md` → never repeat a topic that was already made (made so far: target fixation tree, red button reactance, marching bridge resonance, rooftop pigeons; reference channel already did: rocket cart vs army, roller-coaster loop shape, railroad expansion gaps — avoid those too).
2. The formula (every topic must have all 5):
   - **A real, surprising "why" fact** from science / engineering / psychology / history-of-inventions (one sentence, true).
   - **A fictional place** with a funny name (Grumbleton, Puddlebrook, Fizzwick…) and **fictional characters** (no real people, brands, countries, cities, creators).
   - **An escalating disaster**: the thing goes wrong in 3 bigger and bigger steps (small → silly → chaos).
   - **A weird fix** that works and nobody understands.
   - **The explanation** (2–3 lines, a simple playground/kitchen metaphor) + **one punchline** at the end that callbacks a character.
3. Offer the user 3 ideas in one line each, recommend one; if the user said "you choose", choose and continue.

## B. Write the script (this is what the user records in ElevenLabs)
- 120–150 words → 45–55 s. Short sentences. Rhythm in threes.
- **Line 1 = hook with a contradiction**: "X survived Y. It could not survive Z." / "This button does nothing. Everyone presses it."
- Use "…" where the voice must pause for a visual beat, and put the key punch words on their own line.
- Every sentence must be SHOWABLE (an action, an object, a face). No abstract sentences without a picture.
- End: "That's <concept>." + why it still matters today + punchline callback.
- Give the user the script in a code block, ready to paste.

## C. SFX + music list (names the user searches on Pixabay / YouTube Audio Library)
- 14–20 SFX in story order: `| # | search words | on which line |`, plus 2–3 music moods (start / chaos / explanation).
- Always include: `whoosh` (scene moves), 1–2 impact sounds, 1 crowd reaction, 1 comedy sting/ta-da for the end, 1 ambience bed.
- Ask the user to number the files (`05-drum.mp3`) and send a zip. Use ONLY those files.

## D. Shot plan (after the voice arrives and words.json exists)
One row per ~1 s: `time | words | place | characters + face + body reaction | visual life | camera rig | SFX`. Then build (AI_START_HERE.md step 7).
